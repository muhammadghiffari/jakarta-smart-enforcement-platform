```
AI OPEN INNOVATION CHALLENGE 2026, Case Provider: DISHUB DKI JAKARTA.
Case 1: INTELLIGENT TRAFFIC ENFORCEMENT AND BEHAVIOUR ANALYSIS
```

```
Brief Explanation: Road user discipline issues include illegal parking,
violations of dedicated lanes (busway/bicycle), and public transportation that
picks up and drops off passengers outside of their designated stops. Current
oversight still relies heavily on manual personnel in the field.
```

```
Main Challenges: The limited number of officers compared to the size of the
monitoring area and the difficulty of mapping dynamic (moving) violation-prone
points. How can we transform traffic monitoring as a basis for automated
analysis of road user behavior patterns? It is necessary to optimize the use of
existing systems for monitoring and enforcement of violations, such as using
road cameras, cameras owned by the Transportation Agency, enforcement
socialization, user data, citizen reports, direct monitoring, CRM/public
complaints, system supervision, CCTV and E-TLE.
```

```
Challenge: Participants were asked to develop an AI model that was capable of:
```

```
1) Detect types of violations (illegal parking, special lane occupancy) in real-
time via CCTV. 2) Recognize vehicle identity (ANPR) and duration of violation in
prohibited areas. 3) Mapping hotspots of negative road user behavior (points
where illegal parking occurs).
```

```
Scope & Limitations: The proposed AI model solution needs to consider the
following scope and limitations: 1) Capable of identifying static (parked) and
dynamic vehicles (busway/bicycle lanes) by detecting license plates (ANPR),
vehicle type, and duration of stopping in prohibited areas. 2) The analysis was
carried out on protocol roads and areas around public facilities
(stations/markets). 3) The input data uses existing CCTV video streams with
various viewing angles. 4) Limitations: Varying CCTV video quality and lighting
conditions (night/rain).
```

```
Expected Output: Model: 1) Automatic violation detection algorithm and license
plate identification. 2) Analysis, classification and integration and automation
of CRM reports. Dashboard: 1) A spatial-temporal violation heatmap dashboard,
violator behavior statistics, and an integrated violation database to support
electronic ticketing (E-TLE). Simulator: 1) Recommendations for officer
placement points or E-TLE camera installation based on the level of
vulnerability to violations. 2) The combination of violation types sent to the
relevant unit. Executive Summary: 1) Analysis of monitoring results for the
trial. 2) Daily results analysis and stakeholder reports. 3) Increased public
reporting participation.
```
